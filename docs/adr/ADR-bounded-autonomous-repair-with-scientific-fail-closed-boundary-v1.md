# ADR: Bounded autonomous repair with scientific fail-closed boundary v1

Status: Accepted

Codex may repair deterministic parser, index, adapter, schema, validator,
identity, metric, documentation, and test defects when local evidence supports
the repair. Local Source recovery precedes any external retrieval plan.

Scientific ambiguity fails closed. The workflow must not choose comparators,
factor applications, methods, conflicts, comparability, differences, or
explanations; call Providers; use a network; download content; execute human
annotation; or create Human Gold.

The loop is capped at six iterations and every iteration requires evidence and
verification. Core annotation is bundled by exact Observation identity,
optional method enrichment is separated, and readiness differences are
reconciled per ID with explicit denominators.
