# ADR: Lossless Core Projection and Explicit Comparative Linkage v1

Status: Accepted

Projection must reference the full immutable experimental core and historical Projection must not be edited. Comparator links require an explicit or deterministically unique source basis; direction cannot substitute for a comparator. Measurement Method can be recovered only through explicit Measurement, Evidence, or validated Context identity relationships, and Method absence remains distinct from Measurement absence.

Linkage completeness is split by relation type. Structured core missing a comparator is not text-only. Offline recovery precedes Provider planning, and core-blocking remediation is separate from enrichment.

This ADR does not authorize Provider calls, re-extraction, Conflict conclusions, Comparability, Explanation, ebd5 adjudication, dataset release, Atlas activation, or downstream scientific recomputation.
