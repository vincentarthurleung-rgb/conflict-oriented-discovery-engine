# ADR: Observation Remediation and Candidate Dependency Separation v1

Status: Accepted

Remediation Needs are Observation-scoped and deduplicated. Candidate
dependencies only reference needs and are active only for qualified,
Context-blocked Candidates. Policy coverage review is distinct from ordinary
recovery. A need may serve multiple Candidate references.

Legacy Candidate-endpoint recovery requirements remain immutable and receive a
read-only migration audit. No artifact created here authorizes Provider,
network, automatic recovery, rule extension, payload mutation, Comparability,
Explanation, ebd5 adjudication, or Formal conflict.
