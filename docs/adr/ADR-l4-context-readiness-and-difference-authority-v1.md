# ADR: L4 Context Readiness and Difference Authority v1

Status: Accepted

Candidate qualification does not imply Context readiness. An independent L4
Entry Gate requires two validated authoritative Contexts before authoritative
Difference materialization. Entry readiness does not imply materialization;
Difference validity does not imply new authority.

Recovery is represented only by non-executable requirement sidecars.
Historical Difference artifacts remain immutable diagnostics unless all new
authority contracts pass. Difference authority confers neither Comparability,
Divergence Explanation, nor formal conflict.

This ADR accepts no Granularity Bridge mapping, L4b scientific policy, ebd5
adjudication, automatic recovery strategy, or Formal conflict rule.
