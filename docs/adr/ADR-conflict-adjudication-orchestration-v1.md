# ADR: Conflict Adjudication Orchestration v1

- Status: **Accepted**
- Decision date: **2026-07-25**
- Scope: scientific orchestration and staging authority boundaries

## Decision

Observation Context remains at L2.5. L3a must perform Claim Alignment before
standard future candidate generation. L3b must produce an explicit
Contradiction Signal. Historical candidates are preserved through migration
sidecars rather than rediscovery.

L4b runs Factor Comparability and Factor Divergence Explanation in parallel.
L4c performs one pair-level adjudication over both branches plus alignment,
signal, candidate, and Context Difference identities.

Comparable does not mean conflict. Context difference does not mean explanatory
divergence. A validated contradiction is not a formal conflict. Formal
confirmation requires complete attribution and explicit gate authority.

## Scientific semantics

The orchestration decision is Accepted. Comparability Model B and Divergence
Explanation effect semantics remain **Proposed** and inactive. This ADR
authorizes no severity mapping, explanatory-effect derivation, multi-factor
aggregation, pair adjudication, or production activation.

## Compatibility

The earlier layer-separation ADR remains valid and is not rewritten. This ADR
extends it by replacing the over-linear L3/L4 staging orchestration with
alignment, contradiction provenance, parallel attribution, and a unified
decision boundary.
