# ADR: Source-grounded resolution before Provider re-extraction v1

Status: Accepted

Unresolved linkage is not automatically a Provider requirement. We first construct task-specific Source Envelopes, keep current scientific authority separate from historical extraction lineage, prefer deterministic recovery, and route multiple candidates to future human annotation.

Source non-reporting requires complete audited scope. Incomplete source becomes a separate reingestion requirement. Annotation targets do not create Gold or scientific authority. Provider Candidate is planning-only and carries no execution authorization. Method enrichment is separate from core linkage blocking.

This decision does not authorize Provider calls, automatic annotation, Gold creation, Conflict/Comparability/Explanation decisions, ebd5 adjudication, dataset release, handoff, Atlas activation, active-pointer changes, or Variational EM.
