# Pilot source-bound scientific comparison v1

This is a bounded adapter inside PilotCaseExecutor, not a new semantic extractor
or an authorization contract. Outputs are AI_PROVISIONAL_NOT_INDEPENDENTLY_VALIDATED.

## Current call graph

PilotCaseExecutor: frozen intake → source selection/handoff → B3 inclusion →
frozen Builder V4/Quality V2 → existing V3/Core hydration/validation → existing
candidate linkage/materialization refusal → optional existing AI review →
Evidence Projection → shadow_alignment stage → pilot_comparison.run_comparison →
context_analysis → contradiction_classification → hypothesis → existing dataset
export → existing Atlas case review/import and paginated evidence presentation.

A pinned `scientific_comparison_assessments` input binds VERSION, exact frozen
question identity, source propositions and explicit eight-axis pair assessments.
All biological facts cite B3 observation-scope evidence. Inclusion rows must be
independently source-validated at that scope; paper inclusion is not inherited.
All facets, including absent values, retain uncertainty. Result direction is
separate from scientific proposition identity. Exact source paths/hashes, native
observation/experiment/revision/readiness, original packets, linkage candidates,
Projection outputs, intake, inclusion revisions and effective implementation
identity are bound. A changed derived assessment does not change an identical
raw-provider request's cache key or require duplicate payment.

Without this input the current path reports NOT_EVALUATED and abstains. It does
not substitute legacy lexical comparison. `legacy_shadow_v1` is an explicit
compatibility option restricted to fixture + offline + authentic_seen_replay;
it preserves older package reader/replay semantics, not current scientific
qualification. Existing ai_review_shadow and portable historical pair validators
remain unchanged so immutable historical packages still validate.

## Reused contracts and adapters

- Existing InclusionLedger verifies ArticleJSON coordinates and original JATS
  supplemental anchors. Existing load_bound_packet validates frozen packets and
  original JATS paragraph projections. No second anchor conversion is added.
- Proposition construction reuses StructuredSemanticValueV1,
  InterventionPropositionV1, CausalEvidentialModeV1,
  ExperimentalContrastSemanticsV1 and make_scientific_proposition_signature_v1.
  This constructor's signature is a diagnostic of source facets, NOT a new
  native Core output. Biological canonical identities stay null; structural
  signatures confer no authority. Native endpoint IDs do not establish identity.
- Eight-axis diagnostics reuse DimensionCompatibilityAssessmentV1 with a
  separate explicit Work assessment and source references. They do not invoke
  evaluate_scientific_proposition_compatibility_v1 with fabricated integrity
  decisions or historical-alignment IDs. A provisional MATCH is not validated
  local/external identity, even when labels happen to match.
- Context analysis reuses FactorDifference and its nullable/missing semantics.
  Role-level assessments, not string inequality, determine same/different.
  Different systems or doses may be compatible with bounded question scope.
- Existing create_pending_factor_comparability and
  create_pending_divergence_explanation require validated ContextDifference,
  migration bindings, contradiction signals and entity integrity. Validated
  comparability/explanatory effects additionally require policy/adjudication
  authority. These are NOT synthesized for source-only diagnostics.
- Existing scientific-entity integrity and ordered candidate qualification →
  L4a → L4b → explanatory power → L4c gates stay intact. No missing prerequisite
  is passed as a fake validated object or via historical `None` compatibility.
- Existing SourceResolutionEnvelope objects remain in native linkage inputs:
  task-specific factor/comparator/method scope stays partial. B4 consumes their
  immutable artifact bindings and does not upgrade completeness/authority.
- Existing V2 linkage/readiness and Evidence Projection execute unchanged.
  Reviewable diagnostics can remain visible when native readiness blocks reuse;
  they do not enter materialized Core or formal qualification.
- Hypothesis validation requirements and hyperedge builder are reused only
  after the bounded provisional screen succeeds. Proposals require an explicit
  supported modifier, additional assumptions, unknowns, falsifiable prediction,
  distinguishing design and limitations. No first-difference selection, random
  score, do-calculus, posterior or automatic explanation sufficiency is used.
  Run-local hyperedges are unscored. Empty hypothesis lists are valid outputs.

## Qualification and dependence

Eight axes cover entity, intervention/exposure, focal contrast, endpoint, assay,
system, conditions and source support. Unknown is neither equal nor unequal.
Explicit experimental arms and comparator orientation precede sign comparison.
Different proposition, insufficient evidence and noncomparable are distinct.
P > 0.05 is not a zero effect, equivalence or an opposite direction. Opposing
signs with missing relevant context abstain. Each modifier's source support and
explanation sufficiency are independent fields; sufficiency stays UNCERTAIN.

Within-publication pairs are retained dependency records, never cross-paper
replications. Independent publication identity does not establish independent
cohorts. Denominators distinguish publications, known native experiments,
missing experiment identities, observations, observation pairs, publication-pair
groups, comparability, provisional disagreements, unresolved pairs and hypotheses.
No accuracy or contradiction rates are produced from software controls.

## Limits

This version consumes explicit bounded Work assessments, not arbitrary text or a
universal classifier. It has no approved B2 grounding policy, independent review
or canonical/Strict Core authority. Authentic current examples yield zero
contradiction candidates and zero hypotheses. Synthetic positive program paths
are labeled SOFTWARE_FIXTURE and excluded from biomedical datasets.
