# Experiment Context Scope and Propagation v1

An authoritative scope requires an explicit historical experiment group,
stable experiment index, deterministic source structure, structured scope
reference, or an explicit extraction contract. Same paragraph, similar text,
shared subject, or downstream pairing never establishes scope.

Propagation requires validated scope, registry permission, direct shared source
evidence, observation membership, matching applicability, and no local or scope
conflict. It is same-document only, uses no vote or LLM adjudication, and marks
the origin `deterministic_scope_inheritance`.
