# Conservative source-semantic assessment v1

Owner-approved scope: D1–D5 provisional assessment/rejection/abstention only;
D6 option A (quantitative single-myofiber histological CSA stays reviewable_unknown);
D7 receipt/verifier infrastructure only. Machine-reuse issuing policy and
independent scientific authorization remain NOT_APPROVED.

A source-bound structured semantic annotation is input, never proof of independent
scientific validation. Reuse exact B2 typed endpoints/source anchors, B3 scope
inclusion and B4 source propositions. Preserve native factor roles and model output.

1. Bind source document/bytes/blocks, native observation/Core revision, experiment
   scope, measurement and exact original response/proposal index.
2. Verify existing typed relation endpoints. A result cannot replace an observation
   or Core revision in a scope relation. Identify native measurement-result repeats;
   a repeated edge is not discovery or independent evidence.
3. Consume affirmative evidence for focal factor/exposure/observational grouping,
   tested/reference arms, shared conditions, cohort descriptors and measured
   baselines. Shared conditions and cohort context never become focal contrasts.
4. Require explicit result-bearing tested arm and source-supported reference.
   Unknown orientation abstains; tested arm as reference is unsupported. Native
   comparator labels alone provide no semantic authority.
5. A cohort label is not a measured baseline. Require actual source baseline binding;
   preserve missing values and statistical nonsignificance without equivalence or
   negative-effect inference.
6. Combine Results/captions/Methods only using existing exact source and declared
   scope/endpoint applicability checks. Record every evidence anchor's original
   provider-request presence separately from later supplementation. Topic, proximity,
   cardinality and valid IDs alone do not establish applicability.
7. Preserve ambiguity, conflicting annotations and unknown measurement identity.
   B3 EXCLUDED cannot enter supported downstream semantics; UNCERTAIN abstains.
   Unknown measurement classification is retained separately from known raw
   measurement identity; it cannot be force-mapped to morphology_marker_panel.
8. Provisional statuses: SUPPORTED_PROVISIONAL, EXISTING_NATIVE_RELATION,
   CONTEXT_ONLY, UNSUPPORTED, AMBIGUOUS, ABSTAIN. They do not enable materialization.

Companion receipts bind original index/candidate, source/blocks/spans, applicability,
relation/orientation, conclusion/reasons, policy/owner decision, issuer permission,
validator implementation and immutable lifecycle revision. Current verification is
an independently computed companion result, not a mutable receipt self-assertion.
Only provisional provenance mechanics can verify. Missing/unverified/expired,
revoked/superseded, stale or out-of-scope receipts fail closed. Software-fixture
issuers are test-only. No new machine/scientific issuer is enabled; all verifier
results set machine_reuse_authorized, scientific_authorization, human_gold,
strict_core_eligible, formal_conflict_confirmed and causal_qualification to false.

A valid receipt structure is not semantic truth, issuer authentication, independent
human review or authority. Existing materialize_linkage and formal L4 gates stay
unchanged and are never fed a newly promoted candidate by this adapter. Retain all
historical raw inputs, native Core, source references and scientific decisions.
