# Research-grade Observation + Context Extraction Contract v2

Status: `pending_smoke_validation`; production: `not_activated`.

The candidate contract jointly returns experiment scopes, atomic observations,
experimental factors, measurements, observed results, local/shared context,
and evidence references. Every object has a stable local ID. Results reference
measurements; comparative results reference factors or a baseline; multiple
interventions retain role and order.

The contract emits candidate structure only. It does not emit canonical
identities, Claim Alignment, Formal Conflict, Context Difference,
Comparability, or Divergence Explanation. V1 remains available and the active
pointer is unchanged.
