# Scientific identity evidence preparation V1

This opt-in evidence handoff issues no identity, alias, measurement, comparator,
causal, scientific or machine authority. It does not modify existing gates,
propositions, Core records, B3 decisions or B4.9 correspondence. L4c is staging_only.

Request scientific_identity_evidence is an exact path/SHA-256 Configuration pin.
Each selected item pins a frozen B4 proposition revision/bundle, B3 ledger,
native/Core and effective projection when they exist, and the established B4.9
binding revision where applicable. Frozen and current revisions remain distinct.
Existing immutable correspondence is verified and retained without rematching.

Source mention (exact source substring), StructuredSemanticValueV1 structured-only
term, lexical NormalizationDecision, candidate IDs, EntityMentionEvidenceV1,
LocalEntityEquivalenceDecisionV1, operational measurement description, scientific
verification and formal eligibility remain separate. Existing raw signatures
and Core canonical fields are not filled. Direction is not an identity field.

Only the existing default registry is probed with ResolverCascade: explicit
registry, empty external_clients, execute/network/API/lookup/LLM/cleaner all off;
no local-cache namespace. Existing candidates, if any, remain candidate-only;
this contract has no approved scientific verification/issuer acceptance branch.
There is no new ontology, identifier table or automatic gene-name resolver.
Exact source-substring checks may validate a mention's surface string only.
Validated scientific type/role and cleaner clearance remain absent/warning. Local equivalence
is evaluated by the existing candidate contract without fabricated canonical IDs
or validated type. Every required field retains explicit unresolved integrity.
The existing ScientificEntityIntegrityGateV1 and require function receive a
nonempty list of actual field states; None/empty legacy compatibility is unused.

Nine evidence roles are existing proposition field roles, not scientific entity
classes: subject, object, biological entity, measured entity, intervention or
observational grouping, endpoint, cohort, comparison and result. They bind raw
facet pointers and exact spans; scientific interpretations remain provisional.
A retrospective biomarker stratum is not an assigned intervention; recognition
of a protein name cannot authorize gene-to-survival causation. Operational
endpoint/assay, sample scope and reference orientation have separate unresolved
fields. Source Methods supplements use the existing packet validator; they do
not retrospectively establish original model-input exposure.

Review packets bind exact evidence and current revisions, requested decisions,
alternatives, limits and required reviewer/issuer policy. No review is recorded
or reviewer assigned. Existing B4.6 receipts verify provisional provenance only;
expired/revoked/out-of-scope receipts cannot verify scientific identity. No new
identity verification system, issuer or review authentication is implemented.

Input/policy/implementation and transitive bytes invalidate derived execution
identity. Raw provider request cache identity remains exact and unchanged.
