# Experimental Observation Linkage v1

Supported relations are factor-to-measurement, measurement-to-result,
result-to-comparator, result-to-baseline, factor ordering/co-occurrence, and
observation-to-experiment-scope.

Authority may come from stable local IDs, explicit nested structure, a
deterministic scalar one-to-one legacy structure, validated historical
structure, or a versioned adapter. Co-location and text distance never create
an authoritative link. Duplicate local IDs, dangling references, and
unscoped cross-observation references fail closed.
