# Measurement method enrichment pool v1

Optional method targets live outside the core annotation queue. Each record
states current granularity, scope, expected value/cost, reuse impact, priority,
pilot eligibility, and expertise requirements.

P2 is a 9–18 record pilot. P3 is the retained optional backlog. Missing
coverage dimensions are reported explicitly when no qualifying source record
exists; semantic-level evidence is never promoted to a specific method.
