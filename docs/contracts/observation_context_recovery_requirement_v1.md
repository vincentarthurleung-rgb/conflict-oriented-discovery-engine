# Observation Context Recovery Requirement v1

This strict sidecar records a missing, unvalidated, mismatched, or
policy-coverage-blocked endpoint Context. It is not an execution request.
Provider, network, automatic execution, and historical mutation authorization
must all be false. Policy coverage failures require policy extension review
and are not network retries.

This Candidate-endpoint-scoped contract is deprecated and retained read-only
for compatibility. It is replaced by Observation Remediation Need, Candidate
Context Blocking Dependency, and Policy Coverage Review contracts.
