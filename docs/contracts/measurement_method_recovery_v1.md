# Measurement Method Recovery v1

Method recovery preserves `method_raw`, `method_extracted`, and `method_canonical` separately. Explicit Measurement fields have priority. A validated local Context `assay` or `measurement_method` may be linked by identity. Shared scope recovery requires a validated Experiment Scope. Localization, sample type, semantic level, and endpoint are not methods.

An empty Method is not evidence that the source failed to report it.
