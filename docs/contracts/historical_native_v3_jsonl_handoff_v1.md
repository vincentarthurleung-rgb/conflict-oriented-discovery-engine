# Historical native V3 JSONL handoff v1

Explicitly selected via Pilot `native_representation_handoffs[pmcid]`, a pinned
`historical_native_v3_jsonl_handoff_v1` manifest. Default historical packet readers
and scientific schemas are unchanged. This is an offline representation adapter,
not a new extractor, assembler, classifier, issuer or scientific policy.

Pin original XML, frozen paragraph ArticleJSON, provider block/request/prompt/raw
response, original JSONL, converter/producer files and exact ordered native record
inventory. Replay the frozen paragraph projection (itertext then collapse whitespace,
without NFKC or dropped references). Verify every projected paragraph and complete
provider-block framing with exact unique whole-paragraph matches. Ambiguous mapping
is UNRESOLVED_SOURCE_LINEAGE. XML byte offsets are NOT_AVAILABLE.

Keep provider-block Unicode offsets, projected paragraph Unicode offsets, XML
parsed paragraph indices/selectors, anchor_id and evidence_span_id separate. Use
existing anchor generation/resolution and draft parser/hydrator; require native
records to exactly equal actual retained-provider rehydration. Validate every
original formal V3 without filling fields. Detect missing, malformed, duplicate,
conflicting or reordered records. Preserve original raw JSONL bytes through pinned
file, byte ranges and exact per-line hashes. Preserve original observation IDs,
experiment IDs, order, source XML hash and raw scientific values.

Only verified records reach existing `assemble_v3`. New envelopes and mapped packets
are derived revisions with content bindings. Explicit compatibility reader reruns
the source/native proof and existing assembly, validates exact derived packet/Core,
and uses the unchanged legacy reader for ArticleJSON evidence checks without
pretending the native XML hash equals the packet's JSON hash. Parsing success,
lineage success, handoff success and Core assembly are reported separately.

No mapping from B4 packet propositions to native records by cardinality, name
similarity or array index. B3 inclusion remains independent; new native scopes
without explicit inclusion evidence stay UNCERTAIN. B4.6 conservative sidecars remain
provisional, and missing original linkage-stage interfaces remain explicit. A
successful source proof grants no linkage classification, materialization, active
grounding version, machine reuse, scientific authorization, Gold, Strict Core or
formal L4. All new wrappers and audit records explicitly deny those authorities.

Keep clinical biomarker strata observational, endpoints and subgroup scopes
distinct, and common publication/cohort dependence explicit. Preserve nonsignificant
native directions as recorded with a limitation; never infer zero effect/equality.
No old observational projected Core or its canonical/classification fields is reused
as newly assembled Core. Dataset and isolated Atlas expose source/native availability
separately from B4 proposition availability. Actual input bytes, schemas, assembler,
adapter and policy invalidate derived identity; exact raw request cache stays separate.
