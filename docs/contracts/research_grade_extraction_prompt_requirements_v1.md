# Research-grade Extraction Prompt Requirements v1

Status: Proposed / Pending Smoke Validation

The candidate contract emits one atomic observation per result and does not
merge experiments. It preserves raw subject/relation/endpoint phrases,
intervention roles and order, comparator, measurement, result, context,
quantitative/statistical statements, and explicit uncertainty/value-state
candidates. Every material field references source evidence. It must not infer
unstated information.

The model must not decide claim alignment, contradiction validity, candidate
qualification, context difference, comparability, divergence explanation,
formal conflict, or hypothesis validity.

This contract is not activated. A separately authorized small paid smoke test
is required before production use; bulk-paid readiness is not claimed.
