# Experimental Observation Machine Reuse Readiness v1

This gate labels candidates for secondary machine analysis; it is neither
Human Gold nor dataset release authority. Complete structures can become
`machine_reusable_candidate`; structurally limited records can become
`usable_with_major_limitations`; claim-plus-evidence records lacking a
computable core become `text_evidence_only`.

Non-experimental claims are counted separately and never pass this gate.
Readiness has no authority over Formal Conflict.
