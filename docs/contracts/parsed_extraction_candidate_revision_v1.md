# Parsed Extraction Candidate Revision v1

A parsed revision references one raw-response identity and records parser and
schema versions, payload hash, warnings, errors, fragments, and supersession.
It is immutable. Parse failures are revisions too. Parsed success is not schema
validity, scientific validation, normalization, or human confirmation.

Alignment, contradiction, qualification, comparability, explanation, formal
conflict, and hypothesis-validity fields are forbidden in the candidate payload.
