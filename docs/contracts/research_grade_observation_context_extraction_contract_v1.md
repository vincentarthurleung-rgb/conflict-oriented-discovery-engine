# Research-grade Observation + Context Extraction Contract v1

Status: **Proposed — Pending Smoke Validation — Not Activated**.

One future Provider call returns explicit experiment scopes and atomic
observations. Each observation links to a scope and carries claim, ordered
experimental chain, local Context, result, and stable evidence references.
Shared and local Context fields preserve source phrases and value-state
candidates.

The model does not produce canonical identities or decide alignment, conflict,
Context Difference, comparability, or divergence explanation. Offline
deterministic systems own those operations. Bulk secondary Context calls and
automatic retry are disabled; any retained endpoint is selective,
budget-authorized, block-deduplicated, cache-first, and raw-first.
