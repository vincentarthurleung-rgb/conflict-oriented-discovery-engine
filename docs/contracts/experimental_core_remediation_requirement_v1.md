# Experimental Core Remediation Requirement v1

Remediation records missing components, first-loss stage, available offline
recovery, raw/parsed/evidence status, minimal source scope, and a source-block
deduplication group. They are planning artifacts only.

`automatic_execution_authorized`, `provider_call_authorized`,
`network_call_authorized`, and `budget_authorization_present` are strict false
literals. No remediation record executes a Provider call.
