# Source-aware native/proposition binding V1

This is a source-bound Work provisional correspondence contract. It never issues
scientific, canonical, comparator, measurement-equivalence, machine-reuse, Gold,
Strict Core or formal L4 authority. ScientificEntityIntegrityGateV1 is unchanged.
L4c remains staging_only. All scientific records remain immutable.

Opt-in request key: native_proposition_binding, an exact path/SHA-256 pin of a
Configuration in pilot_native_proposition_binding.py. The configuration pins
original B4.7 lineage, B4.8 raw/effective projections, original B4 propositions,
B3 ledger, native replay manifest, owner instruction and this policy. Sources
are publication-specific. No hash is substituted for a different representation.
The existing B4.7 replay/reader and B4.8 source verifier are reused unchanged.

Explicit Work field assessments bind exact record content, Core/proposition and
inclusion/effective revisions, original raw record pointers/values, and existing
source evidence references. Local analysis labels are not canonical identities
or an ontology. No clinical text classifier, fuzzy matching, record ordering,
count matching, P-value threshold or new model extraction is used.

Representation replay and semantic correspondence are separate checks. Every
native and proposition profile must be supplied for each selected publication.
Native Results evidence must overlap the proposition Results evidence at exact
projected coordinates, with equal explicit endpoint, subgroup, scope kind,
design, measurement and reported-result assessments. Known conflicting timing,
statistic, result-group or reference-group assessments prevent a match. Unknown
required fields or no same-result-coordinate support remain UNRESOLVED. Multiple
plausible matches become AMBIGUOUS; no tie break. Known differences are NONMATCH.
A source-supported unique match is SOURCE_BOUND_PROVISIONAL_MATCH only. Unknown
reference/timing fields remain explicit; matching them does not authorize
comparator orientation, causal sign, effect magnitude or cross-paper equivalence.

The sidecar binds frozen and current revisions separately and retains exact
coordinates, source representation lineage, source envelopes, evidence per field,
original B3 decisions and dependencies. Unmatched native records are retained;
no B3 decision is inherited or promoted. Existing source proposition and native
paths remain independent. Derived cache identities include transitive binding
input bytes, policy and implementation; raw provider-request cache identity is
unchanged. Structural validation is never independent scientific approval.

Historical and current B3 revisions are retained separately. Relocation of a
byte-identical source to a new run changes the revision identity. The adapter
recomputes both identities and permits only source_artifact/revision_identity
to differ; all scientific decisions/evidence and original source hashes must
remain identical. Neither revision number substitutes for the other.
