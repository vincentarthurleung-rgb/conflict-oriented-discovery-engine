# B3 source-grounded scientific inclusion v1

This is a development inclusion/coverage contract, not a new scientific Core
admission policy. `case_stages_v4` inserts scientific_inclusion after immutable
handoff and before Builder. Historical stage contracts v1–v3 remain verifiable.

A pinned ResearchIntakeResult must bind the exact frozen question and one of the
six existing DomainProfiles. Missing/malformed/incompatible inputs explicitly use
the existing deterministic_degraded parser with zero current model calls. Historical
mode and API counters are retained as recorded, not attested as a new model run.
Pinned frozen_search_plan.v1 uses its existing drift-checking replay loader;
validated proposition-aware plans use their existing validator. Original frozen
case identity may be explicitly retained by a derived case stratum. No planner is
called. Domain context, paper design cue inventory, experiment design and specific
question applicability are separate; paper domain remains UNKNOWN absent evidence.

The ledger consumes pinned source-applicability assessments. It does not classify
arbitrary scientific prose or infer equivalence from names/pathways. Criteria are
explicit string-valued intervention, entity, endpoint, biological_system, comparator,
study_design and timepoint fields of the frozen question scope. Direction, desired
contradiction, significance, effect size and canonical identity are not criteria.
Every affirmative/mismatching criterion requires exact source evidence and source
wording. The original ArticleJSON section or hash-bound original JATS node projection
must reproduce text, Unicode coordinates and hash. XML offsets are projected-node
coordinates, never claimed to be raw XML byte offsets. The assessment's semantic
correctness remains provisional, even when its source integrity passes.

INCLUDED: all explicit criteria source-assessed as supported. EXCLUDED: an explicit
criterion is source-assessed as mismatching. Otherwise UNCERTAIN, including absent,
invalid, ambiguous or unavailable source scope. Missing fulltext never supplies a
scientific-exclusion reason. Retrieval eligibility/exclusion remains separate.

Paper, experiment and observation decisions are independently keyed. A paper decision
is never inherited by an observation. Experiment IDs from native V3 remain candidate
scope identities, not certified independent experiments. Existing figure-bound source
packets may be included without a new V3; packet decisions do not count as new model
extractions or native Core assembly. Fulltext/measurement canonical IDs are not invented.

Source-excluded papers retain source/plan/decision artifacts and abstain from model
processing. Excluded observations retain unmodified V3/Core/packets in native tables,
but do not proceed to linkage, review/projection or alignment. UNCERTAIN stays
reviewable and may continue only under the existing separate model/source/Core gates.
Negative/null findings are treated identically; null is not equivalence.

Coverage records retrieval rows/dedup/SEEN, access states, independent scope decisions,
planned regions/windows and their actual states, new real versus software model
requests, replayed/hydrated observations, rejected/unresolved observations and native
linkage readiness. Unknown retrieval/window denominators remain unknown. Character
windowing is not scientific extraction; empty Builder/Quality is not zero relevant
observations. `pipeline_complete` remains false; attempt terminal, inclusion assessment,
extraction and downstream scientific stages remain separate. No publication recall
is estimated.

Actual frozen input bytes and adapter/policy code affect derived execution identity.
Completed packages reject drift and require new immutable revisions. Exact provider
raw cache identity remains provider endpoint + canonical body + fixture namespace;
raw data may be reused and rederived under current inclusion dependencies at zero
new charge. New dataset tables and Atlas display fields are additive. Native scientific
contracts and permissions are unchanged. A bounded offline development stop is explicit
and cannot silently mark later scientific stages completed.
