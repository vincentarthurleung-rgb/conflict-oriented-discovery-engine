# Pilot source-grounded linkage stage v1 (B2 development integration)

`case_stages_v3` inserts `source_grounded_linkage` immediately after
`experimental_v3_core`. Historical stage contracts v1/v2 remain verifiable.
This engineering sidecar does not amend a scientific schema or acceptance policy.

The stage reassembles the exact V3/Core revision, replays the retained original
response through the existing parser/hydrator, and checks pinned response,
validated observation, window, source text and coordinates. New V3 derivations
retain those inputs per record; historical annotations without the lineage are
reported as unavailable, never reverse-engineered into a provider response.

Optional source supplements are pinned catalogs and scope/component/applicability
bindings. Original JATS projections and explicit figure cross-references are
verified. Methods and panel applicability remain supplied provisional scientific
assessments; exact hashes do not independently certify meaning. Source resolution
envelopes use existing contracts and retain partial scope and incomplete historical
provider-input authority because supplements were not all in the original request.
The original V3, component evidence arrays and native Core remain unchanged.

Execution modes:
- No configured linkage model stage: unsigned prepared request, no transport.
- Pinned Work candidate assessment in an explicit offline fixture: assessed as Work
  proposals, not provider linkage extraction or an independent review.
- Explicit model-stage/budget configuration: reuse the existing owner-gated
  transport, reservations, raw capture/cache, receipt validation and unknown-outcome
  guards. Fixture transport outputs remain labeled as software fixtures.

Original responses, per-edge structural rejections, unresolved information,
materializer rejection codes and separate native/hypothetical V2 diagnostics are
exported. Negative, malformed, truncated, failed and interrupted outcomes remain
reviewable; no fabricated fallback or automatic retry of an unknown outcome.
Atlas serves the original evidence and provisional decisions in its existing
case scientific-page route; no new identity or reviewer-authority system is added.
New dataset exports require a new empty destination. `pipeline_complete` is false:
this Pilot does not certify full original L0–L6 scientific execution. Source-window
processing coverage and explicit scientific-stage records are separate fields.

## Unapproved scientific decision required for machine reuse

The materializer continues to reject candidate authority and an absent deterministic
grounding version. A scientific owner must separately approve a versioned semantic
grounding contract specifying the permitted relation classes, exact experiment and
component binding, affirmative evidence requirements, cross-region group/panel/
Methods applicability, comparator semantics, ambiguity/missing-evidence rejection
rules, permitted validation authority and provenance, and immutable revision/
revocation behavior. Only an implementation evaluated against that approved
contract could assign its grounding version or permitted reuse authority. Neither
a structurally valid model response nor this Work assessment can assign it.
Independent scientific authorization, Human Gold and Strict Core remain separate.

For quantitative single-myofiber histological CSA, the separate minimum registry
decision is whether the approved meaning of `morphology_marker_panel` covers that
operational endpoint. If not, retain unknown until a general classification contract
is approved. Whole-muscle geometric CSA used in specific force is not substituted.
CTX shared injury is not the Ar-deletion contrast; observed decrease does not grant
a formal molecular causal regulatory edge. No measurement rule is changed by B2.
