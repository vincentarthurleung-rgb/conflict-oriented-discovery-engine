# Dose-stratified direction reversal v1

Owner scope: `runs/20261104_code_dose_stratified_diagnostic_v1_offline/owner_instruction.original.txt`.
This additive source-local exploratory diagnostic is independent of A/B/C/D,
scientific qualification, formal L4, Gold, hypotheses and benchmark policies.

The exact `_relation_key` remains unchanged, including dose and condition. A new
context-comparison identity retains the verified source hash and publication,
source-local evidence family, active tested subject/agent/primary role/operator,
target, operational endpoint, assay, system, duration and tested/reference arms.
Other extracted factor/system context must match exactly. Declared dose text is
replaced only in copies of design/scope labels used by this parallel identity;
all original observations and exact keys retain it. No input is mutated.

Only dose varies. The existing controlled intervention operation must be known
and agree exactly, alongside its raw operation label and bound intervention
evidence; raw noun/verb inflections are not used to reclassify that operation.
V1 excludes multiple/secondary/rescue interventions, unknown or
unattested agents, dose, comparator, system, duration, endpoint or readout. It
requires verified packet/source bindings and component evidence, exact source
surfaces for relevant fields, and a tested relation subject matching the primary
agent. Descriptive readout content tokens must occur in measurement-bound evidence;
this structural check is not a semantic review or ontology/canonical identity grant.
Non-dose raw design/scope differences abstain by separate comparison identities.
No fuzzy aliases, unit conversion, cross-time/cell/publication equivalence is used.

Doses must have explicit numeric values/ranges and units attested by bound source.
Units match exactly after Unicode glyph normalization. A range stays one aggregate
stratum. Opposing signs must occur in distinct, disjoint dose intervals; overlap
does not invent a bin-specific result. Conflicting directions within one dose
abstain. Only existing eligible screening directions support the label. UNKNOWN
statistical state does not imply significance, nonsignificance or zero effect;
unscoped NS wording is not converted into observation-level NS.

Output schema: `dose_stratified_direction_reversal_v1.schema.json`. Diagnostic label:
`DOSE_STRATIFIED_DIRECTION_REVERSAL`. There is one label per source family, with
positive/negative strata, exact result evidence, separate raw/source/effective/
screening signs and uncertainty. Shared original result coordinates/hashes are
counted as shared spans even when IDs differ. Repeat extractions deduplicate by
source result/dose/relationship, not extraction IDs. Three dose observations are
not three independent studies: publication count is one, independent-publication
replications zero, biological/experimental independence unknown. No conflict
entropy or contradiction probability is pooled or estimated.

Production integration: `discover_directions` invokes the parallel diagnostic
after existing deduplication; `run_initial_discovery` first performs the existing
source/packet/block validation. Direct projection rows lacking that verification
abstain rather than silently receiving a verified label. Existing Pilot receives
the additive nested output through its existing initial stage. Dataset exports a
separate diagnostic payload table; table row counts are not positive-family counts
and do not affect A/B/C/D. No production Atlas write is required or authorized.

Dependency manifests bind this module, schema and contract. Old completed packages
require a new immutable derived revision; provider requests, raw cache identity,
scientific gates, frozen schemas and historical A/B outputs remain unchanged.
