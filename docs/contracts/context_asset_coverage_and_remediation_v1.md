# Context Asset Coverage and Remediation v1

Coverage has Observation × Registry Field granularity and separately records
Observation prompt request, Context prompt request, representation, Provider
return, parser preservation, historical migration, evidence, validation,
normalization, consolidation, and recovery availability.

Remediation is planning only. It prefers existing validated Context, existing
candidate, authoritative Raw reparse, Parsed recovery, exact anchor recovery,
scope propagation, validator/normalizer/consolidation replay, selective
Provider extraction, then source reingestion. All execution, Provider, network,
and budget authorizations default to false.
