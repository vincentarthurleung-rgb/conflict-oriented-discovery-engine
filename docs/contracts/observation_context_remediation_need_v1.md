# Observation Context Remediation Need v1

This strict Observation-level contract identifies a current Context debt.
Its deduplication identity excludes Candidate ID, endpoint role, Qualification,
Entry identity, pair ordering, run name, and timestamp. Candidate IDs are
audit-only reverse references.

Open and policy-blocked needs authorize no provider, network, download,
automatic execution, payload mutation, Composition mutation, or Registry
mutation.
