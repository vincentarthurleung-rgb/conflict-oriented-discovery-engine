# Experimental Core Projection and Comparative Linkage Repair v1

This offline architecture repairs loss at the projection boundary without changing historical extraction assets. `experimental_core_projection_v2` is lossless by identity reference: Factor, Measurement, Observed Result, Linkage, Evidence, Context, integrity and readiness remain independent immutable authorities.

Comparison semantics are evaluated per Result before comparator completeness. Direction is never a comparison policy. Comparator recovery accepts an existing direct reference, a deterministic nested reference, or an exact and unique syntactic evidence reference. Candidate edges are audit aids and their scores never grant authority.

Measurement Method recovery is independent of Measurement existence. It may bind an explicit validated `assay` or `measurement_method` Context Field Evidence record from the same Observation. Scope inheritance requires a validated Experiment Scope. Original Measurement and Context values are never overwritten.

Completeness is reported independently for Measurement→Result, Factor→Measurement application, comparative reference, and evidence. Machine-reuse readiness consumes those axes but grants neither Human Gold nor Formal authority. Remediation is a planning sidecar with every execution authorization fixed to false.

The offline run is `runs/20260725_hif1a_experimental_core_projection_comparative_linkage_repair_v1_offline`. It does not activate Projection v2 or trigger Alignment, Qualification, Difference, Comparability, Formal Gate, Candidate, Atlas, or Provider workflows.
