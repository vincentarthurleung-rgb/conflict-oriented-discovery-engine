# Source-grounded Experimental Linkage Resolution and Annotation Triage v1

This offline layer separates missing structured fields from execution requirements. It reads immutable experimental-core, context, evidence, and currently ingested full-text assets and emits only new sidecars.

The processing order is: build a task-specific Source Envelope; audit source scope; apply exact deterministic rules; route ambiguity to an annotation target; distinguish source non-reporting from incomplete ingestion; then produce remediation and Machine Reuse v3 candidate sidecars. Current full text is scientific authority, but is never represented as proof of the historical Provider input.

Comparator resolution requires an explicit local reference or exact comparison syntax plus a unique exact Factor phrase. Direction and a unique control are not authority. Factor application requires explicit structure, arm IDs, Result references, or source syntax; a single Measurement does not create an all-to-all graph. Method resolution separates specific methods, assay families, and semantic levels and never guesses from an endpoint.

Provider candidacy is planning metadata and every execution authorization remains false. Annotation tasks are unexecuted, abstention-enabled, and do not create scientific authority or Human Gold. Readiness v3 is candidate-only and does not replace v2.
